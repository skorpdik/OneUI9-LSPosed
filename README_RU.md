# One UI 9 Motion – сборка APK для LSPosed

**В архиве ИСХОДНИКИ, не установочный APK.** Автоматическая сборка в GitHub Actions добавлена, но ещё не запускалась — успешная компиляция не подтверждена.

## Собрать APK на телефоне без ПК
1. Создай новый **приватный** репозиторий на GitHub.
2. Через сайт GitHub загрузи **содержимое** архива в корень репозитория (не один ZIP и не дополнительную вложенную папку). Особенно нужна папка `.github/workflows/`.
3. Открой вкладку **Actions → Build LSPosed APK → Run workflow**. При первом использовании GitHub может попросить включить Actions.
4. Если сборка прошла успешно, открой завершённый запуск, секцию **Artifacts**, скачай **OneUI9-LSPosed-alpha-APK** и распакуй его. Там будет `app-debug.apk`.
5. Установи APK, затем в LSPosed включи модуль **только для One UI Home**, перезапусти лаунчер. Если есть сбои — сразу выключи модуль в LSPosed.

## Реальное поведение
Экспериментальный хук перехватывает `ViewPropertyAnimator.setInterpolator` **в процессе One UI Home** и подменяет некоторые интерполяторы на `OvershootInterpolator(0.45f)`. Хук не рассчитан на SystemUI и не создаёт Liquid Glass. На One UI 9 / Android 17 не проверен, а часть анимаций лаунчера может не использовать этот метод — эффекта может вообще не быть.

## Важно
Этот код был подготовлен под современный libxposed API 102, но **не собран и не установлен для реального теста**. Не отключай штатную защиту, не расширяй scope на SystemUI. Для отката отключи модуль в LSPosed и перезапусти лаунчер.
